# Capability Matrix — Data & Platform Capabilities Across the Four Research Modules

Status: **Phase A reference document. No code, no migration, nothing activated.**
Companion to `docs/PORTFOLIO_RESEARCH_ROADMAP.md` (module definitions) and
`docs/SF1000_SPEC.md` (the one module whose spec depends most heavily on the
gaps below). Modules: **A** = existing U.S. equity paper probation, **B** =
Signal Forge 1000 (SF1000) paper index research, **C** = options
education/simulation, **D** = future forex (design only).

Every row is grounded in a file path, a measured provider probe recorded in
this repo, or is explicitly marked `(unverified)`. Status values:

| Status | Meaning |
|---|---|
| **supported today** | Entitled and already wired into a running module |
| **delayed data** | Entitled, but latency is `DELAYED` (≥15 min) or `END_OF_DAY` — never `REALTIME` |
| **simulated/provisional** | Computed locally from inputs, explicitly labelled as not a vendor value, or an as-of (not point-in-time) proxy |
| **unsupported** | No entitlement on the current plan (confirmed by a `403`/probe) |
| **requires new data entitlement** | Would need a different subscription/product than what's licensed today; schema may exist but is unpopulated |

|---|---|---|---|---|
| Alerts — global gate | supported today, OFF | `src/signalforge/alerts/dispatch.py::run_alert_cycle` — reads `alerts_enabled` app setting, defaults `False` | Every alert type additionally gated per-type (below); every body carries "Research signal only — no order was placed." | A |
| Alerts — candidate type | supported today, OFF | `alerts/dispatch.py::ALERT_TYPE_SETTING_KEYS[AlertType.CANDIDATE]`; requires `paper_probation_enabled` **and** an exact dataset-scope match (`research/approval_scope.py::scan_scope_matches`) | Structurally cannot fire for a strategy that isn't `PAPER_APPROVED` on the exact scan scope it was approved against | A |
| Alerts — system_health / data_issue / daily_briefing | supported today, OFF | same file, `ALERT_TYPE_SETTING_KEYS` | Overnight-eligible (`overnight_ok=True`); independent of the candidate cap | A |
| Options-trade alerts | unsupported (by design) | import-linter contract **S11** (`pyproject.toml`): `signalforge.options` may never import `signalforge.alerts` | No code path exists, not merely disabled | C |
| Live order execution (`signalforge.execution`) | **not built; authorised in writing, paper endpoints only, nothing armed** | `docs/decisions/0003-execution-layer.md` (full text `docs/research/options_designs/D6_execution_adr.md`), approved 2026-09-12; contracts **S15b** (live) and **S15a** (staged) in `pyproject.toml`; safety tests T1–T13 in `tests/safety/test_s15_execution_boundary.py` | Zero lines of execution code exist today.
